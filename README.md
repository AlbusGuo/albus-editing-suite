# Editing Suite

[English](README_EN.md) | 简体中文

Editing Suite 是一款面向 Obsidian 的编辑体验增强插件. 它在保留 Markdown 文件可移植性的同时, 提供编辑器排版, 表格, 链接, 数学公式, 代码, 分隔线和补充语法等功能.

*让编辑与阅读尽可能像同一张纸.*

## 核心能力

### 编辑器基础

- 使用滑块调整正文宽度
- 按住 `Alt` 并滚动鼠标滚轮快速调整正文宽度
- 在 Live Preview 中折叠标题井号, 光标回到标题开头时重新显示
- 折叠段落末尾或紧贴前一块的 `^id`, 选择所属块时重新显示
- 使用焦点指示器标记当前行, 标题级别和嵌套列表层级
- 通过 `编辑与阅读模式对齐 (实验性)` 统一常见块元素的间距与位置

### 单笔记字体

在笔记属性中使用 `font` 或 `字体` 指定当前笔记的字体:

```yaml
---
font: Microsoft YaHei
---
```

也可以使用中文属性名:

```yaml
---
字体: 宋体
---
```

属性值输入框支持搜索已安装的系统字体并预览字体外观. 设置只作用于当前笔记的编辑模式和阅读模式. 如果两个属性同时存在, `font` 优先.

### 表格

- 独立控制表格全宽与表格居中
- 提供默认, 圆角网格和三线表样式
- 保留 Obsidian 原生表格编辑与拖拽交互

### 链接

- 保留 Obsidian 默认链接样式
- 可选红色线框链接样式
- 阅读模式与编辑模式同步生效

### 数学公式

- 调整行间公式上下边距
- 在空间不足时允许行间公式横向滚动
- 对带 `\tag` 的公式进行双模式间距适配

### 代码

- 优化行内代码样式
- 在阅读模式点击行内代码复制内容并显示反馈
- 为代码块显示标题栏, 语言名称与语言图标
- 支持代码块行号, 长行换行和复制按钮
- 在阅读模式与编辑模式中保持一致的代码块结构

### 分隔线

- 保留 Obsidian 默认分隔线
- 可选菱光渐变样式
- 整条分隔线均可触发 hover 反馈

## 补充语法

### 彩色文本

彩色文本使用粗体语法和圆形 Emoji 作为标记:

```md
**🟡黄色文本**
**🟢绿色文本**
**🔴红色文本**
**🟠橙色文本**
**🟣紫色文本**
**🔵蓝色文本**
```

默认只保留文字颜色. 启用 `保留粗体` 后, 彩色文本同时保留粗体字重. 普通粗体不受影响.

### 彩色高亮

彩色高亮扩展 Obsidian 的 `==文本==` 语法:

```md
==🟡黄色高亮==
==🟢绿色高亮==
==🔴红色高亮==
==🟠橙色高亮==
==🟣紫色高亮==
==🔵蓝色高亮==
```

Live Preview 和阅读模式会隐藏颜色 Emoji. 在 Obsidian 1.14 及以上版本中, 光标进入对应范围后显示官方可交互色块. 普通 `==高亮==` 仍使用 Obsidian 默认样式.
高亮下方的波浪线可以在设置中单独关闭, 不影响颜色背景和色块交互.

### 挖空

黑色圆形 Emoji 用于区分彩色高亮与挖空:

```md
==⚫需要隐藏的内容==
```

挖空内容默认隐藏, 可通过点击, 键盘或编辑交互显示.

### 负标题

使用 Discord 风格的 `-# ` 创建紧凑, 弱化的标题:

```md
-# 普通负标题
-# 支持 **粗体**, *斜体*, 链接和 $E=mc^2$
- -# 列表中的负标题
> -# 引用中的负标题
\-# 转义后作为普通文本
```

`智能切换负标题` 命令支持单行, 多行, 列表和引用, 并跳过代码块, 数学块及 Frontmatter.

### 侧边标注

使用以下语法在正文左侧或右侧显示边注:

```md
正文内容{{📝这里是边注}}
```

- 编号按照文档顺序自动生成
- 边注跟随正文锚点, 重叠时自动向下顺延
- 可选择在正文左侧或右侧显示
- 横向空间不足时使用弹层
- 边注支持 Markdown, 数学公式和图片渲染
- 打印或导出 PDF 时转换为脚注
- 边注不支持嵌套

### 自定义有序列表

在普通 Markdown 有序列表的第一项中加入格式指令:

```md
1. {a)} 第一项
2. 第二项
3. 第三项

1. {I.} 第一项
2. 第二项

1. {第 3 条} 第一项
2. 第二项
```

支持数字, 大小写字母, 大小写罗马数字, 自定义前缀和后缀. 底层仍使用 Obsidian 有序列表结构, 因此可以继续使用原生缩进, 折叠与列表交互.

可以在格式指令后添加 `-` 取消列表与相邻内容的视觉间距. 该行为适用于正文、引用、Callout 和嵌套列表, 不依赖实验性双模式对齐:

```md
> [!note]
> Callout 内容
>
> 1. {（1）}- 第一项
> 2. 第二项
```

## 设置

设置页包含两个页面:

- `编辑器`: 正文宽度, 单笔记字体, 标题标记, 焦点指示器, 双模式对齐, 表格, 链接, 数学公式, 代码和分隔线
- `拓展`: 彩色文本, 彩色高亮, 挖空, 负标题, 侧边标注和自定义列表

功能开关和样式选项保存后立即生效.

## 安装

### 手动安装

1. 下载 `main.js`, `manifest.json` 和 `styles.css`
2. 创建 `<Vault>/.obsidian/plugins/albus-editing-suite/`
3. 将三个文件放入该目录
4. 重新加载 Obsidian
5. 在 `设置 -> 第三方插件` 中启用 Editing Suite

升级时替换三个发布文件并保留 `data.json`, 以继续使用已有设置.

### 从源码构建

```bash
npm install
npm run lint
npm run build
```

生产构建会在项目根目录生成 `main.js`.

## 兼容性与隐私

- 最低支持 Obsidian `1.13.0`
- 插件使用 Obsidian 与 CodeMirror 提供的本地 API
- 不包含遥测, 分析, 广告或远程服务
- 不会将笔记内容, 文件名或设置发送到外部服务器
- `编辑与阅读模式对齐` 属于实验性功能, 复杂主题或其他排版插件可能影响最终结果
