# Editing Suite

Editing Suite 是一款 Obsidian 社区插件, 用于增强 Obsidian 默认编辑能力与 Markdown 语法体验

## 当前状态

项目当前处于基础开发阶段, 初始版本为 `0.1.0`

## 彩色高亮

使用圆形 Emoji 前缀扩展 Obsidian 的高亮语法:

```md
==🟡黄色高亮==
==🟢绿色高亮==
==🔴红色高亮==
==🟣紫色高亮==
==🔵蓝色高亮==
```

彩色高亮在 Live Preview 和阅读视图中隐藏 Emoji, 光标进入高亮时重新显示 Emoji, 源码模式始终显示完整语法

普通 `==高亮==` 仍使用 Obsidian 默认高亮样式

插件只将 🟡🟢🔴🟣🔵 识别为彩色高亮前缀, `⚫` 保留给挖空语法

插件提供以下命令:

- 高亮为黄色
- 高亮为绿色
- 高亮为红色
- 高亮为紫色
- 高亮为蓝色

## 彩色文本

使用粗体语法作为彩色文本载体:

```md
**🟡黄色文本**
**🟢绿色文本**
**🔴红色文本**
**🟣紫色文本**
**🔵蓝色文本**
```

5 种彩色文本都必须包含对应的圆形 Emoji, 插件会移除载体的粗体外观, 只保留文字颜色

启用 `保留粗体` 后, 彩色文本会同时保留粗体字重

彩色文本使用分别适配浅色和深色模式的正文色板, 与彩色高亮的柔和背景配色相互独立

彩色文本在 Live Preview 和阅读视图中隐藏 Emoji, 光标进入彩色文本时重新显示 Emoji, 源码模式始终显示完整语法

普通粗体和普通行内代码不受影响

插件提供以下命令:

- 文本着色为黄色
- 文本着色为绿色
- 文本着色为红色
- 文本着色为紫色
- 文本着色为蓝色

## 挖空

使用黑色圆形 Emoji 标记挖空内容:

```md
==⚫需要隐藏的内容==
```

插件会在阅读和实时预览状态下隐藏答案, 点击或悬停时显示内容

## 负标题

使用 Discord 风格的 `-# ` 语法创建紧凑的弱化标题:

```md
-# 普通负标题
-# 行内公式 $E=mc^2$
-# 数学公式 $$E=mc^2$$
- -# 列表中的负标题
> -# 引用中的负标题
\-# 转义后按普通文本显示
```

负标题支持源码模式, Live Preview 和阅读视图, 保留粗体, 斜体, 链接和数学公式等 Markdown 渲染结果

插件提供 **智能切换负标题** 命令:

- 光标位于单行时切换当前行
- 选择多行时按多数状态统一添加或移除 `-# `
- 普通文本占多数或数量相同时统一添加
- 负标题占多数时统一移除
- 转换原生标题时移除原有的 `# ` 标记
- 列表和引用中的标记会插入到结构前缀之后
- 代码块, 数学块和 Frontmatter 中的内容不会被命令修改

## 设置

插件设置页可以独立启用或停用:

- 彩色高亮
- 彩色文本
- 负标题

功能开关修改后立即生效, 不需要重新加载插件

## 开发环境

- Node.js 18 或更高版本
- npm
- TypeScript
- esbuild

安装依赖:

```bash
npm install
```

启动开发构建:

```bash
npm run dev
```

执行生产构建:

```bash
npm run build
```

执行代码检查:

```bash
npm run lint
```

## 构建产物

生产构建会在项目根目录生成 `main.js`, 发布时需要包含以下文件:

- `main.js`
- `manifest.json`
- `styles.css`, 仅在项目包含样式时需要

## 手动安装

将发布文件复制到以下目录, 然后在 Obsidian 的 **设置 -> 第三方插件** 中启用 Editing Suite:

```text
<仓库目录>/.obsidian/plugins/albus-editing-suite/
```

## 开发规范

项目遵循 Obsidian 的 [Plugin guidelines](https://docs.obsidian.md/Plugins/Releasing/Plugin+guidelines), 功能代码按职责拆分, 插件入口仅负责生命周期与模块注册
